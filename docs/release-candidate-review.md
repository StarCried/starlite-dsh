# StarLite 本地发布候选验收

本轮只做本地准备，未推送或发布。请先阅读入门说明，再检查实际体验；动画、观感和交互由你确认，自动测试不替你标记通过。

## 本轮新增的 Windows Host 验收

以下测试均使用同一个 `dsh-starlite` 候选包，不需要发送付费模型请求。不同 Host 请顺序测试，切换前停止旧 Host 并等待 StarLite 托盘退出。

1. **官方 Desktop**：侧栏「插件 → 添加插件」填候选包的 Windows 绝对路径，安装、启用并按提示重启，确认微光自动出现。双击模型应唤起桌面应用，不开浏览器；正常工作时检查打开的是气泡所指会话，没有会话时应打开主界面。
2. **窗口与退出**：点 Desktop 的 × 后桌宠仍在；从 DSH 托盘真正退出后桌宠隐藏，经过重连期退出。重新打开应用恢复；停用插件后 DSH 仍可使用。
3. **Windows CLI/Web**：按用户指南在 PowerShell 安装同一候选包并启动；双击应打开浏览器中的正确会话或首页，无空控制台窗口。
4. **WSL 与冲突**：原有 WSL 使用方式保持。原 Host 连接时再启动另一个 Host，应有一次明确提示，原气泡、动作和问题不被替换，新 DSH 本身可用。
5. **问答与费用**：普通单选、多选、自定义输入；限时问题、到时继续及补答；隐私或断线后回官方界面。余额只使用官方 API Key，单纯登录桌面账号不应误用登录令牌。已通过的模型外观无需为本次 Host 适配重做验收。

## 阅读

- DSH：本仓库首页 README 和「安装与使用」。普通用户只安装一个 DSH 插件，启动 DSH 即准备 Windows 桌宠；不要求另装桌宠软件、解压模型或配置动作。
- Hexo：StarLite 仓库的 `packages/hexo/README.md` 和 `docs/examples/hexo-vrm.yml`。标准人形 VRM 可直接导入，不需要自定义 ZIP；复杂配置放在进阶文档中。
- 微光：模型卡片的「查看许可」，或单独交付目录中的 `LICENSE-Weiguang.md`。确认个人非商业 DSH／Hexo 使用、博客必要托管、技术适配、署名和禁止事项符合你的意图。程序许可与模型、动作许可分别适用。

公开 npm 安装命令只能在正式发布后执行；本地候选使用提供的 tarball。预览网址和本机模型下载服务不能作为公开分发地址。

## 测试

1. **首次使用**：按安装说明启动已装插件的 DSH，微光自动出现，设置和许可入口容易找到，没有空命令行窗口。
2. **模型设置**：现有微光动作、偏好保持；「查看导入说明」可打开、滚动、关闭；「添加 VRM 模型」直接选文件。若有自己的无动作模型，检查默认站姿、呼吸、眨眼、限角头眼跟随；身材差异可能仍需调整权重或姿态。
3. **日常互动**：模型身体可拖动，透明处可操作下面的程序；单击回应，双击在无会话时打开 Web UI。现有会话导航、费用卡和工作气泡可在你正常使用 DSH 时顺便确认，不必为了验收调用付费模型 API。
4. **动作与气泡**：微光手指、表情、耳朵、尾巴、大动作边界和回待机正常；工作期间不触发点击／偶发动作。精简／详细气泡、普通单选／多选／文本问题的排版和可操作性也需要人工检查，工具审批留在 DSH。
5. **博客预览**：先看到正文，再加载模型；首访入场、点击和偶发动作与句子对应；切换页面不重新加载或重复入场。最大化、长文本、页面底部和点击穿透均正常。手机默认不下载运行时和模型。
6. **退出与恢复**：关闭 DSH 后桌宠隐藏，并在重连期结束后退出；重新启动恢复。若使用多屏、缩放或睡眠，检查恢复后的位置、命中和物理。断线检测最多 45 秒，断连后保留 60 秒重连期。

已有通过的项目无需重复确认；本轮新默认待机、单 VRM 博客入口和新候选包需要再看一次。测试结果请按编号告诉我，出现问题就先修复，不继续发布。
