# 让 DSH 会话控制角色

简体中文 · [English](session-control.en.md)

这是可选功能，默认关闭。它让当前 DSH 会话用角色的动作和气泡回应你，不增加独立聊天服务、人格记忆或语音系统。人格仍由你的 DSH 会话提供。

## 开始使用

1. 在角色右键菜单的「DSH」页或完整设置中开启「允许会话控制角色」。
2. 在 DSH 中发送：

   > 使用 StarLite 与我互动。先查看当前模型可用的动作，再临时接管角色，用一个适合打招呼的动作和简短气泡回应我。结束后恢复普通工作状态。

3. 接管期间，将光标移到角色附近，脚下工具栏会多一个机器人按钮。它表示角色正由会话控制，点击即可退出；右键菜单也保留「退出会话接管」。

无需配置 MCP 地址或另装 Skill。插件向兼容的 DSH 注册原生工具和使用说明；工具只在此开关开启时提供，取得控制还需要角色已就绪。旧版 DSH 缺少所需工具服务时，普通桌宠仍能运行。

## 接管时会发生什么

- 普通工作状态、偶发互动、单击回应和费用展示暂时让出角色；基础站姿、自然眨眼和物理继续运行。
- 会话可以一次提交动作与文字，让二者同时开始。接管气泡只显示正文，不附带会话标题。动作必须来自当前模型的实际列表，不支持生成新动作或指定文件路径。
- 可以临时移动角色、调整大小或光标跟随；释放后恢复原来的布局和偏好。移动限制在当前显示器工作区内。
- 「显示气泡」关闭或隐私模式开启时，会话不能强行显示自定义文字。拖动、暂停、隐藏、换模型等用户操作优先，会结束当前接管。
- 普通输入题交回 DSH；权限审批始终使用 DSH 原有界面。
- 同一时间只有一个会话控制角色。其他会话会得到忙碌结果，不排队抢占。

连续五分钟没有接管会话的新 Agent 输出（文字、思考或工具调用）或有效控制操作，才会自动释放；持续对话可以超过五分钟。其他会话的消息、连接心跳和单纯查询不续期。停止、取消、断线或会话销毁仍会释放，恢复最新的实际工作状态。重连后不会重放旧动作或自动恢复接管。

## 工具范围

| 工具 | 用途 |
| --- | --- |
| `starlite_inspect` | 查看模型、动作名称与时长、能力和当前接管状态 |
| `starlite_control` | 获取或释放本会话的接管权 |
| `starlite_perform` | 播放一个动作、显示纯文字气泡，或停止当前表演 |
| `starlite_stage` | 临时调整位置、大小和光标跟随 |

气泡最多 1000 个字符，显示时间为 1–30 秒；大小限制为 50%–150%；位置使用当前屏幕可用范围内的 0–1 相对值。工具会报告实际开始、完成、中断或拒绝，不把“已发送”当作“已播放”。不支持无限动作队列、任意脚本、截图或读取屏幕内容。

## 用于其他聊天插件

QQ、B 站等插件若将消息交给有这些工具的 **同一个 DSH 会话**，就能按需使用角色展示。StarLite 不连接这些平台，也不替它们发送消息。是否公开显示聊天内容、如何触发回复以及人格设定，仍由你和对应插件决定。不要把整个聊天记录塞入气泡；优先使用简短、适合当前场景的回应。

此功能不额外发起模型推理。让 DSH 的 LLM 决定动作时，会使用你原有的模型服务并按其规则计费。动作播放与本机工具通信本身不消耗模型 token。参见[联网与存储说明](network-and-storage.md)。
