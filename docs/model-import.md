# 模型导入与动画约定

桌宠只接受 Inochi Creator 导出的 `.inp`。导入器调用 `inochi2d-pipeline` 检查资源、Web 兼容性和动画清单，在应用数据目录中创建准备后的独立副本。检查、构建、复检和配置写入全部成功后才切换模型。

## 动画映射

| 状态 | 是否必填 | 播放方式 | 结束条件 |
|---|---:|---|---|
| Idle | 是 | 循环 | 进入其他状态 |
| Thinking | 否 | 循环 | 状态改变 |
| Working | 否 | 循环 | 所有工具结束或更高优先级状态出现 |
| Approval | 否 | 循环 | 批准完成 |
| Blocked | 否 | 循环 | 下一次 turn 开始 |
| Completed | 否 | 单次 | 保持完成状态 6 秒 |
| Error | 否 | 单次 | 保持错误状态 8 秒 |
| Click | 否 | 单次 | 只允许 Idle 点击；播放后恢复 Idle |

映射使用精确动画名，区分大小写。可选项选择“禁用”后只保留模型中性姿态和 ambient 动画，不会回退到 Idle，也不会由网页程序模拟肢体动作。尾巴、呼吸、头发和袖子等应由模型自身 ambient 动画与物理完成。

建议模型作者使用上表中的英文名称，以便导入向导自动预选；这只是命名约定，不是强制参数规范。不同模型可以保留自己的参数范围和动画设计，用户在下拉框中完成映射。

## 失败与授权

下列情况会阻止导入：文件损坏、资源越界、不支持的模型功能、准备过程异常、缺少 Idle、映射名称不存在或准备后复检失败。失败不会删除或覆盖当前可用模型。

模型只存储在本机，不上传、不遥测。导入功能不改变模型版权；用户必须自行确认使用权。公开安装包内的“微光”演示模型必须在 `assets/microlight/ASSET_LICENSE.md` 中提供独立、明确、可再分发的授权，否则发布检查必然失败。
