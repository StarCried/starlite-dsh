# 会话气泡与模型互动

工作气泡默认使用精简模式：第一行是对应会话的标题，第二行是思考、输出、运行命令、编辑文件、读取、搜索或压缩等状态。右键模型身体打开设置，在「工作气泡」中选择详细模式，可显示标题及原有思考／回答内容。切换气泡模式不会重新加载模型。隐私模式使用固定标题和状态，不显示会话内容或输入题目。

DSH 等待普通用户回答时，气泡显示题目、单选／多选及自定义输入。所有题目都有有效回答后才能提交；单选的自定义回答与选项互斥，多选可附加文字。详情可展开，长表单可滚动。输入草稿仅在当前窗口内存中保留，取消、会话切换、断线或开启隐私模式后清除。每个回答只接受一次且必须匹配仍待答的请求。「转到 DSH 回答」先交回答题权，再打开对应会话。工具权限审批继续在 DSH 中确认。

单击模型身体保留互动动作和费用展示。工作状态沿用现有规则，不播放点击动作；正在回答问题时，费用不会覆盖表单。为了区分双击，单击在约 350 毫秒后执行。双击打开气泡所指的会话；没有会话引用时打开 DSH Web UI 首页，失效引用则显示不可用。拖动、右键及透明背景点击不会触发这两个动作。

模型使用公共桌宠气泡层。状态协议 v1 增加可选标题、固定活动码和随机引用；题目与回答走单独的认证、有大小限制的接口。真实会话身份和登录 URL 由 WSL 中的 DSH 构造并交给浏览器，桌宠只发送临时引用。原生鼠标命中区域仅额外包含正在显示的表单，其他透明区域继续穿透，手动全窗口穿透设置仍优先。

## 桥接与会话导航

桥接运行在 WSL2 DSH 内，通过 IPv4 loopback 上带临时令牌的状态流连接独立 Windows 程序。桥接随 DSH 销毁；Windows 程序断连后隐藏，保留 60 秒重连期后退出。停滞连接先经过最多 45 秒心跳检测。缺少 Windows 程序或 DSH 事件契约不兼容时只禁用桌宠，不阻止 DSH 启动。

仅在输入界面连接且可见时，桌宠才接管普通单选、多选或文字问题。禁用输入或断线会交还 DSH 的原有回答器。回答有大小限制，只能提交到一个仍待答的请求；不拦截工具权限审批，也不提供通用 agent 控制接口。

双击使用短期随机会话引用。真实会话 ID 和认证 URL 由 WSL 侧解析并直接交给浏览器，Windows 桌宠不会收到它们。Web 客户端先查询权威会话目录再消费 URL fragment 导航提示；不会创建会话或发送提示。失效或被替换的引用会被拒绝，不跳转到其他会话。

## 余额与今日费用估算

费用功能只按需请求 `GET https://api.deepseek.com/user/balance`，余额缓存 60 秒，不调用付费模型接口。凭据由 DSH credential service 解析，不复制到 Windows。支持默认 `llm-deepseek`／`deepseek-official` 和可选的 `llm-pi-ai.providers.deepseek` 路由；两者都有凭据时使用默认原生路由的余额。

在 DSH「模型」页配置官方 DeepSeek API Key 即可，不需额外的 pi-ai profile。原生路由遵循其配置的端点和受信任的 `DEEPSEEK_BASE_URL` 启动覆盖；自定义网关、模型级端点或认证覆盖不触发余额请求。缺少凭据时显示未配置，不发请求。服务商返回负余额时保留原值。

今日估算只读当前 profile 已有的会话记录，包含重启前记录，不另存历史或财务账本。日期使用 Asia/Shanghai；排除 fork 继承事件，同一次尝试的重复结算只保留最新一次，重试单独计数。只统计经核实的官方端点和价格表中的 Flash／V4 Pro 模型 ID；未知模型、缺失用量和读取不完整明确标注，不伪造价格。Reasoning token 已包含在输出 token 中。

同一官方账户的模型共用余额，但用量按实际记录的模型计价。原生和 pi-ai 配置属于不同账户时，卡片标明余额配置，今日估算仍覆盖当前 profile 的两个合格路由，并非单个账户账单。更换凭据后，历史用量不能可靠地归属到账户。

价格核实日期为 2026-10-10，依据官方 [CNY](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 和 [USD](https://api-docs.deepseek.com/quick_start/pricing/) 表。金额范围覆盖高峰／空闲价格，不猜测服务商每次请求的实际结算时段。单独徽标显示当前公布的费率时段：北京时间周一至周五的 09:00–12:00 和 14:00–18:00，排除中国公共节假日；其余时段为半价空闲时段。离线 2026 日历依据[官方节假日安排](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，未核实年份的工作日日间标记为未知。每次发布前应复核价格表。

这是 DSH 用量估算，包含范围不等于账户官方账单；未完成请求和其他应用不计入。扫描上限为 512 个会话、每会话 16 MiB／100,000 个事件，达到上限时显示部分估算。凭据或持久化接口不受支持只影响费用查询，不影响 DSH 启动和状态桥接。

发布前的自动检查和人工验收要求见[发布说明](release.md)。实际账户余额需要用户配置官方凭据后验收；自动测试不调用付费模型接口。
