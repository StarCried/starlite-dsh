# 安全与隐私边界

## 信任边界

DSH 插件和 Windows 桌宠通过 `127.0.0.1` 上的只读 SSE 和费用查询通信。每次 DSH 启动生成新的 256 位随机令牌，令牌只存在于两个进程的内存中。服务端使用随机端口，Windows 客户端拒绝非回环地址；协议没有反向控制 DSH 的命令。

深链接只接受固定 scheme、`connect` host、单一 `port`/`token`/`instance` 字段、UUID v4 和 43 字符 base64url 令牌。未知字段、重复字段、非回环目标和畸形消息均拒绝。

临时令牌通过一次 Windows 进程命令行深链接交付，不写文件或注册表。它主要阻止普通网页和无令牌的本地请求，不试图防御已经控制同一 Windows 用户会话、能够读取其他进程命令行或内存的恶意程序；这种攻击者已经处于本产品的本机信任边界内。

## 允许跨进程的数据

允许的数据只有：

- 协议版本、单调序号和发出时间；
- 聚合后的七种桌宠状态；
- DSH 已暴露给对话前端的最新 assistant reasoning/text；
- 工具名或固定状态提示。

费用查询使用独立的 `GET /v1/billing`，沿用相同的令牌与来源限制，不改变状态协议 v1。`billingVersion: 1` 仅允许余额状态、CNY/USD 数字金额、查询时间、北京时间日期、计价/未计价请求数、价格核实日期及估算区间；序列化前重新构造白名单对象。凭据与会话记录始终留在 WSL，Windows 不持有服务商 API 密钥。该接口不记录费用气泡内容。

禁止的数据包括用户消息、系统提示、工具参数、工具结果、批准原因、错误对象/错误栈、文件路径、session/agent 标识和凭据。适配器逐字段构造负载，不会先复制完整 DSH 事件再做删除。

气泡文本去除 ANSI、C0/C1 控制字符，折叠异常空白，最多保留开头 120 个 Unicode 字素（超长时末位使用省略号）；Windows 端用 `textContent` 显示，不解释 HTML、Markdown 或链接，也不持久化内容。固定文案隐私模式会在 Windows 端替换动态文字。

## 故障行为

- DSH 契约不兼容、Windows 程序未安装或拉起失败：桌宠安全停用，DSH 继续启动。
- SSE 令牌错误、消息超限、协议版本不匹配或序号倒退：拒绝消息并重连。
- 模型损坏、越界、不兼容或映射错误：拒绝导入，保留旧模型。
- SSE 断开：立即隐藏模型，托盘保留 60 秒；仍未恢复则退出。

不要把 SSE 端口暴露到局域网，不要把临时深链接或令牌写入日志。发现安全问题时，在公开 issue 中只描述可复现的非敏感现象；涉及秘密或可利用细节时应使用仓库的私密安全报告入口。
