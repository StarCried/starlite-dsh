## 阅读

- DSH：本仓库首页 README 和「安装与使用」。普通用户只安装一个 DSH 插件，启动 DSH 即准备 Windows 桌宠；不要求另装桌宠软件、解压模型或配置动作。
- Hexo：StarLite 仓库的 `packages/hexo/README.md` 和 `docs/examples/hexo-vrm.yml`。标准人形 VRM 可直接导入，不需要自定义 ZIP；复杂配置放在进阶文档中。
- 微光：模型卡片的「查看许可」，或单独交付目录中的 `LICENSE-Weiguang.md`。确认个人非商业 DSH／Hexo 使用、博客必要托管、技术适配、署名和禁止事项符合你的意图。程序许可与模型、动作许可分别适用。

公开 npm 安装命令只能在正式发布后执行；本地候选使用提供的 tarball。预览网址和本机模型下载服务不能作为公开分发地址。

## 既有验收范围（未变更项不重复）

1. **首次使用**：按安装说明启动已装插件的 DSH，微光自动出现，设置和许可入口容易找到，没有空命令行窗口。
2. **模型设置**：现有微光动作、偏好保持；「查看导入说明」可打开、滚动、关闭；「添加 VRM 模型」直接选文件。若有自己的无动作模型，检查默认站姿、呼吸、眨眼、限角头眼跟随；身材差异可能仍需调整权重或姿态。
3. **日常互动**：模型身体可拖动，透明处可操作下面的程序；单击回应，双击在无会话时打开当前 Host 主界面。现有会话导航、费用卡和工作气泡可在你正常使用 DSH 时顺便确认，不必为了验收调用付费模型 API。
4. **动作与气泡**：微光手指、表情、耳朵、尾巴、大动作边界和回待机正常；工作期间不触发点击／偶发动作。精简／详细气泡、普通单选／多选／文本问题的排版和可操作性也需要人工检查，工具审批留在 DSH。
5. **博客预览**：先看到正文，再加载模型；首访入场、点击和偶发动作与句子对应；切换页面不重新加载或重复入场。最大化、长文本、页面底部和点击穿透均正常。手机默认不下载运行时和模型。
6. **退出与恢复**：关闭 DSH 后桌宠隐藏，并在重连期结束后退出；重新启动恢复。若使用多屏、缩放或睡眠，检查恢复后的位置、命中和物理。断线检测最多 45 秒，断连后保留 60 秒重连期。

已有模型、动作和博客验收保持有效；本轮没有更改这些内容，不要求重做。只继续上方尚未完成的 Host 与问答项目，出现问题先修复，不继续发布；没有重测的长时性能、多屏、DPI 或睡眠也不补记为通过。
