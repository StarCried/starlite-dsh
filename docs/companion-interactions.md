# 会话气泡与模型互动

工作气泡默认使用精简模式：第一行是对应会话的标题，第二行是思考、输出、运行命令、编辑文件、读取、搜索或压缩等状态。右键模型身体打开设置，在「工作气泡」中选择详细模式，可显示标题及原有思考／回答内容。切换气泡模式不会重新加载模型。隐私模式使用固定标题和状态，不显示会话内容或输入题目。

DSH 等待普通用户回答时，气泡显示题目、单选／多选及自定义输入。所有题目都有有效回答后才能提交；单选的自定义回答与选项互斥，多选可附加文字。详情可展开，长表单可滚动。输入草稿仅在当前窗口内存中保留，取消、会话切换、断线或开启隐私模式后清除。每个回答只接受一次且必须匹配仍待答的请求。「转到 DSH 回答」先交回答题权，再打开对应会话。工具权限审批继续在 DSH 中确认。

单击模型身体保留互动动作和费用展示。工作状态沿用现有规则，不播放点击动作；正在回答问题时，费用不会覆盖表单。为了区分双击，单击在约 350 毫秒后执行。双击打开气泡所指的会话，而不是任意最新会话；没有会话引用时不打开其他会话。拖动、右键及透明背景点击不会触发这两个动作。

Inochi2D 和 VRM 都使用同一个桌宠气泡层。状态协议 v1 增加可选标题、固定活动码和随机引用；题目与回答走单独的认证、有大小限制的接口。真实会话身份和登录 URL 由 WSL 中的 DSH 构造并交给浏览器，桌宠只发送临时引用。原生鼠标命中区域仅额外包含正在显示的表单，其他透明区域继续穿透，手动全窗口穿透设置仍优先。

## 本地验证（2026-10-08）

- 项目检查：111 项测试、类型、静态检查和构建通过。
- 原生检查：19 项测试及严格静态检查通过；私有资产导入测试本轮未重跑。
- 打包插件：7 个白名单文件；隔离配置验证不兼容时只禁用桌宠、重复销毁安全，没有调用模型 API。
- 真实透明窗口：单选、多选和文字输入成功返回模拟 DSH 请求；恢复两行精简气泡，正确显示会话二和「编辑文件」。
- 双击成功拉起默认 Chrome；内置浏览器的本地认证重定向测试正确定位会话二并清除导航标记。Chrome 页面读取被自动安全检查终止，因为无法确认当前网址，因此没有声称已完成真实 DSH 会话的 Chrome 视觉验收。

本轮未推送、发布模型／安装包或部署博客。普通 DSH 已恢复，未自动提交提示。实际账户余额仍需用户配置后验收。

开发时，同一版本和同一路径的本地 tarball 可能被包管理器复用。本轮已通过源文件哈希比对发现并处理该情况，使用按内容命名的本地安装包安装；安装后的插件文件必须与本次构建一致，不能仅依赖「已安装」提示。
